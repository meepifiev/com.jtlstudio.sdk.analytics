# Changelog

## [1.0.0] - 2026-09-25

### Added

- Цели для JTL SDK: `Analytics.Send("goal")`, `Analytics.Send("goal", data)` и события-объекты через `IAnalyticsEvent.Report(reporter)`.
- Доставка в Яндекс Метрику своим `.jslib`: счётчик берётся из активной конфигурации SDK (поле Yandex Metrica counter в тулките), скрипт метрики поднимается сам при старте игры.
- Вне web-сборки цели пишутся в консоль, если уровень логов SDK - Everything. Пустой счётчик даёт одно предупреждение, а не молчание.
- `Analytics.Reporter` подменяется своим, поэтому события проверяются тестами без сети.
